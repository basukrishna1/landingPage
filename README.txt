# Birthday Memory Archive

## Run locally
Open `index.html` in a browser, or serve this folder with a local static web server.

## Add your photos
Create an `images` folder beside `index.html` and add:
`photo-1.jpg` through `photo-9.jpg`.
The existing HTML uses these paths.

## Personalize
In `script.js`, change `FRIEND_NAME` from `YOUR FRIEND` to the recipient's name.

## New gallery gate
After the scrapbook, the visitor must find all five hidden stars in the second game before the gallery opens.

## Note
The game gate is a client-side experience, not security or access control. A visitor with developer tools can bypass it.
